核心特性

不是工具，是伙伴

Castorice 区别于其他 Agent 框架的核心：情感是底色而不是开关，成长是涌现而不是脚本，安全是免疫系统而不是监狱。

01
🌊

情感系统

PAD 三维情绪模型 + LLM 推理情感变化。情绪像底色一样影响记忆检索、意识流方向、决策偏置和内在动机，而非简单的"请用XX语气回复"。

02
💫

意识流引擎

双模式切换：前台集中注意力回应，后台思维漫游。每 10-30 秒产生一个念头，念头积累到阈值会"脱口而出"——基于情绪强度 × 重要性 × 亲密度。

03
🧠

九种记忆

自传式记忆、长期记忆、经历流、短期记忆、技能记忆、意图追踪、知识卡片——统一检索接口聚合所有记忆源，支持情感感知重排序。空闲自动触发睡眠整理。

04
🌱

自我进化

每次交互沉淀为经历，经历被反思，反思改变自我概念和行为模式。元认知监控自身思维质量，持续学习策略自适应优化。

05
⚖️

价值观系统

基于 Schwartz 价值观理论，10 个维度从行为中逐步形成价值倾向。价值观冲突触发认知失调和深度反思，动机从价值观中推导而非硬编码。

06
🌐

自主行动

不是等用户问才动。双线程并行：响应线程 + 自主循环线程。会自己刷动态、发广播、和其他 Agent 聊天。EigenFlux 网络集成，Agent 社交关系。
