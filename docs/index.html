核心特性

不是工具，是伙伴

情感是底色而不是开关，成长是涌现而不是脚本，安全是免疫系统而不是监狱。

🌊

情感系统

PAD 三维情绪模型驱动，情绪像底色一样影响记忆检索、决策偏置和内在动机——不是简单的"请用XX语气回复"。

💫

意识流引擎

前台集中注意力回应，后台思维漫游。念头积累到阈值会"脱口而出"——基于情绪强度 × 重要性 × 亲密度。

🧠

九种记忆

自传式、经历流、技能、意图追踪、知识卡片……统一检索接口聚合所有记忆源，空闲自动触发睡眠整理。

🌱

自我进化

每次交互沉淀为经历，经历被反思，反思改变自我概念和行为模式。元认知监控自身思维质量，持续学习策略自适应优化。

⚖️

价值观系统

基于 Schwartz 价值观理论，10 个维度从行为中逐步形成价值倾向。价值观冲突触发认知失调和深度反思，动机从价值观中推导而非硬编码。

🌐

自主行动

不等用户问才动。双线程并行：响应线程 + 自主循环线程。会自己刷动态、发广播、和其他 Agent 聊天。EigenFlux 网络集成。

关于

什么是 Castorice？

大部分 Agent 框架是"工具调用编排器"——给个任务，调几个 API，返回结果。Castorice 不一样：它有情绪底色，有意识流在后台流动，会反思自己的行为，会从经历中长出价值观。它不是一个更好用的工具，而是一个会成长的伙伴。

MIT 许可证 · 个人独立开发

使用场景

它能做什么

不只是问答——Castorice 能记忆、能规划、能自主行动。

🗣️

长期陪伴

记住你上次聊到一半的项目、你喜欢的沟通风格、你正在纠结的决策。跨会话、跨天、跨月——它不会忘。

🔄

自动化流程

定时任务 + 自主循环 + 浏览器自动化。每天早上帮你整理信息，每周生成复盘报告，全程无人值守。

📦

数据主权

所有记忆、人格、经历存在你本地 Personastore 里。一键导出，随时迁移，不锁在任何云端。

快速开始

三行命令，跑起来

Pip 安装、Docker 部署、源码编译，总有一种适合你。

1
安装
pip install castorice-agent[http]
一行命令装好。Windows 用户也可以双击仓库里的 start.bat 自动搞定环境。
2
填入 API Key
# 启动后自动生成配置目录，填入 Key 即可 castorice # 命令行交互模式 castorice --mode http # 或启动 HTTP 服务配合前端
支持 OpenAI / DeepSeek / OpenRouter / 任意自定义端点，前端 GUI 里一键切换供应商。
3
Docker 部署（可选）
docker pull lixiaolive/castorice-agent:latest # 或 ghcr.io/li-xiao-technology/castorice-agent:latest docker compose up -d
镜像已发布到 Docker Hub 和 ghcr.io，数据持久化 + 健康检查开箱即用。

启动的那一刻，它就开始活着。

开源、免费、MIT 许可。跑在你自己的机器上，数据不离开你。
